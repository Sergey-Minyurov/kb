title: Проблемы планирования
---

| Проблема                                                                      | Анализ                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    | Решение                                                                                                                                                                                                                                                                                                            |
| ----------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| Запланированные работы не завершаются досрочно                                | Исполнитель не мотивирован выполнить работу раньше. Может использовать остаток времени на изучение технологий. При досрочном завершении могут возникнуть вопросы по точности оценки трудоёмкости или оптимистичные ожидания по дальнейшим работам.  Факторы:<br>- бюрократизация управления проектом и разработки - ответственность за задачи и показатели, но не за конечный результат<br>- потеря понимания и фокуса на продукте и ценностях заказчика                                  | - Делегирование ответственности и повышение полномочий исполнителя для его мотивации<br>- Интеграция планирования и проектирования для осмысленной работы исполнителя                                                                                                                                              |
| Запаздывание распространяется на последующие этапы календарного графика       | Планирование фокусируется на взаимозависимости работ. Асимметрия планирования:<br>- для ускорения одной работы нужно ускорение всех влияющих на неё предыдущих работ (предшественников)<br>- для опоздания достаточно задержки любой предыдущей работы                                                                                                                                                                                                                                    | - Планирование рисков и подготовка мероприятий по управлению рисками<br>- Повышение технологичности проектирования и разработки (формализация, CASE, DSL)                                                                                                                                                          |
| Работы не являются независимыми                                               | Начальные оценки и определение задач неточные и неполные. Поэтому на этапе реализации возникают неожиданные зависимости и сложности.                                                                                                                                                                                                                                                                                                                                                      | - Моделирование и привлечение экспертов для детализации м выявления сложностей<br>- Повышение качества проектирования и архитектуры для снижения блокирующих зависимостей                                                                                                                                          |
| Многозадачность приводит к дальнейшим задержкам                               | Многозадачность может помогать:<br>- при блокировке одной задачи можно переключиться на другую<br>- если задачи связаны, то можно оптимизировать их общее решение<br>Многозадачность мешает:<br>- издержки при переключении между задачами (повышение трудоёмкости и невынужденные ошибки)<br>- быстрые и непродуманные решения, ведущие к переделках<br>- зависимости между задачами, ведущие к задержкам и блокировкам, повторной разработке при недостаточном анализе и проектировании | - Итеративность разработки: ритмичное и раннее представление промежуточных или конечных результёатов <br>- Стандартизация задач: шаблоны анализа, проектирования и программирования<br>- Развитие горизонтальных коммуникаций и построение конвейера по разработке, снятие зависимости от конкретного разработчика |
| Полная и максимальная загрузка приводит к резкому снижению производительности | Отсутствие резервов не позволяет компенсировать неизбежные задержки, которые нарастают как снежный ком.                                                                                                                                                                                                                                                                                                                                                                                   | Планирование резервов                                                                                                                                                                                                                                                                                              |
| Игнорирование ценности определённых функций для заказчика                     | При итерациях планирование выполняется в интересах команды разработки, при оптимизации важные для заказчика функции могут быть исключены или недоработаны.                                                                                                                                                                                                                                                                                                                                | Приоритизация функций для заказчика.                                                                                                                                                                                                                                                                               |
| Не учитывается неопределённость при планировании                              | Источники неопределённости:<br>- неполные требования<br>- изменения требований<br>- неточные оценки при разработке                                                                                                                                                                                                                                                                                                                                                                        | - Итеративная разработка<br>- Детализация при планировании<br>- Гибкая архитектура и обобщение задач (DSL и пр.)<br>- Оценка не является обязательством                                                                                                                                                            |
