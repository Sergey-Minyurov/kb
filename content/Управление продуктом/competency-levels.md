[[knowledge-map|Карту знаний]] можно использовать для оценки и развития PO, выделив три уровня:
1. **Базовый (Junior PO):**
    - понимает основы Agile/Scrum;
    - умеет составлять user stories;
    - работает с Jira/Trello;
    - собирает базовую обратную связь от пользователей.
2. **Продвинутый (Middle PO):**
    - владеет методами приоритизации;
    - анализирует продуктовые метрики;
    - проводит A/B‑тесты;
    - управляет ожиданиями стейкхолдеров.
3. **Экспертный (Senior PO):**
    - разрабатывает стратегию продукта;
    - масштабирует продукты на новые рынки;
    - внедряет инновации;
    - обучает младших PO.
---
### Как использовать карту знаний
1. **Самооценка:** PO оценивает свои навыки по каждому блоку (например, по шкале 1–5).
2. **Обратная связь:** сбор оценок от команды, стейкхолдеров, руководителя.
3. **План развития:** выделение 2–3 ключевых зон для улучшения на ближайший квартал.
4. **Обучение:** выбор курсов, книг, менторов для прокачки навыков.
5. **Практика:** внедрение новых подходов в работу, эксперименты с методами.
6. **Повторная оценка:** через 3–6 месяцев — проверка прогресса.
